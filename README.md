# 회의노트 (MeetNote)

Mac에서 돌아가는 **로컬 AI 회의록 앱**입니다. 회의를 녹음하거나 녹음 파일을 올리면
참석자별로 대화를 받아쓰고, AI가 요약·주제·결정 사항·할 일을 정리한 **회의록**을 만들어 줍니다.
클로바노트·다글로와 같은 흐름으로 쓸 수 있고, 음성은 **이 Mac 밖으로 나가지 않습니다.**

## 주요 기능

| 구분 | 기능 |
|---|---|
| 녹음 | 원클릭 녹음, 일시정지/계속, **실시간 자막**, 녹음 중 북마크·메모, 다른 화면을 보는 동안에도 계속 녹음, 앱이 꺼져도 녹음분 자동 복구 |
| 업로드 | m4a·mp3·wav·mp4·mov·webm 등 음성·영상 파일, 여러 개 동시 업로드, 창에 끌어다 놓기 |
| 받아쓰기 | Apple GPU로 도는 Whisper large-v3-turbo(MLX) 또는 초고속 SenseVoice, 한국어 띄어쓰기·문장부호 자동 교정, **키워드 등록**으로 이름·전문 용어 인식률 향상, 한국어·영어·일본어·중국어 |
| 화자 구분 | 참석자 자동 구분(인원 지정 가능), 이름 바꾸기(전체 적용), 발언별 참석자 변경, 참석자 합치기, 참석자별 발언 비중 |
| 대화록 | 재생 위치 자동 따라가기, **단어 단위 하이라이트(가라오케)**, 단어·시간 클릭하면 그 부분 재생, 더블클릭 수정, 찾기(⌘F)·찾아 바꾸기, 하이라이트, 발언 합치기 |
| AI 요약 | 한 줄 요약, 요약, 주요 주제(시간 링크), **결정 사항**, **할 일(담당·기한, 체크박스)**, 미결 사항, 키워드, 참석자별 요약 |
| 회의록 | 일시·참석자·안건·논의 내용·결정 사항·향후 조치 양식의 정식 회의록, Word 다운로드, 서식 복사, 인쇄/PDF |
| AI 질문 | "누가 무엇을 하기로 했어?"처럼 회의 내용에 질문, 답변 속 시간을 누르면 해당 부분 재생 |
| 정리 | 폴더(끌어다 놓아 이동), 즐겨찾기, 휴지통(복원), 제목·대화·요약 전체 검색(⌘K), 정렬 |
| 내보내기 | Word(.docx) 회의록, Markdown, 텍스트, 자막(SRT·VTT), 원본 음성, JSON |
| 플레이어 | 파형 + 참석자 색 타임라인 + 북마크 표시, 0.5~2.5배속, ←/→ 이동, Space 재생 |
| 기타 | 다크 모드, 마이크 선택·잡음 억제·자동 음량, 모든 데이터 로컬 저장 |

## 설치 (Mac)

필요: macOS 12 이상, 인터넷(설치할 때만), 디스크 약 3GB (Whisper 모델 포함)

1. 이 저장소를 내려받습니다.
   ```bash
   git clone -b claude/voice-meeting-notes https://github.com/XELLOS-1992/LEE.git 회의노트
   cd 회의노트
   ```
2. 설치 스크립트를 실행합니다. (Finder에서 `회의노트 설치.command`를 더블클릭해도 됩니다)
   ```bash
   bash scripts/install.sh
   ```
   - 전용 Python 환경(uv), 필요한 패키지, 음성 인식·화자 분리 모델(약 200MB),
     Apple Silicon이면 Whisper 모델(약 1.6GB)을 받습니다.
   - 끝나면 `~/Applications/회의노트.app`이 만들어지고 실행됩니다. Launchpad·Spotlight에서 "회의노트"로 찾을 수 있습니다.
   - Xcode 명령줄 도구(`xcode-select --install`)가 있으면 **네이티브 앱 창**으로, 없으면 Chrome 앱 창/기본 브라우저로 열립니다.
3. 처음 녹음할 때 마이크 권한을 물으면 **허용**을 누릅니다.

업데이트: `git pull` 후 `bash scripts/install.sh`를 다시 실행하면 됩니다.

## AI 요약 설정 (선택)

앱의 **설정 › AI 요약**에서 고릅니다.

| 방식 | 품질 | 설명 |
|---|---|---|
| **Claude** (권장) | ★★★ | [console.anthropic.com](https://console.anthropic.com)에서 API 키를 발급해 입력합니다. 녹취록 **텍스트만** 전송되고 음성은 전송되지 않습니다. 기본 모델 Claude Opus 5 |
| **Ollama** | ★★ | 완전 오프라인. [ollama.com](https://ollama.com) 설치 후 `ollama pull exaone3.5:7.8b` (한국어 추천) |
| **내장 요약** | ★ | 추가 설치 없이 핵심 문장·키워드·결정·할 일을 규칙 기반으로 추출합니다 |

"자동"으로 두면 Claude 키 → Ollama → 내장 요약 순서로 사용합니다.

## 사용법

- **녹음**: 왼쪽 위 `녹음하기` (⇧⌘R). 녹음 중 `B` 북마크, `Space` 일시정지. `완료`를 누르면 정확도 높은 엔진으로 다시 받아쓰고 회의록을 만듭니다.
- **파일**: `파일 업로드` (⌘U) 또는 창에 끌어다 놓기. 참석자 수·녹음 종류(회의/인터뷰/강의/통화)·키워드를 지정하면 더 정확합니다.
- **참석자 이름**: 대화록에서 이름이나 동그라미를 눌러 이름을 바꾸면 모든 발언에 적용됩니다.
- **수정**: 발언을 더블클릭해서 고칩니다. 잘못 인식된 이름은 `⋯ › 찾아 바꾸기`로 한 번에 고칩니다.
- **다시 변환**: `⋯ › 다시 변환하기`에서 언어·참석자 수·엔진을 바꿔 다시 받아쓸 수 있습니다.

단축키: `Space` 재생/정지 · `←/→` 5초 이동 · `B` 북마크 · `⌘F` 대화 찾기 · `⌘K` 노트 검색 · `⌘U` 업로드 · `⇧⌘R` 녹음 · `⌘,` 설정

## 받아쓰기가 부정확할 때

1. **어떤 엔진으로 변환됐는지 확인**: 노트 제목 아래에 엔진 이름이 나옵니다. `Whisper … (MLX · Apple GPU)`가 가장 정확합니다.
   `SenseVoice`로 나오면 Intel Mac이거나 Whisper 설치가 안 된 경우입니다 (설정 › 모델 관리).
2. **녹음 중 실시간 자막은 빠른 엔진(SenseVoice)** 이라 덜 정확합니다. `완료`를 누르면 Whisper로 처음부터 다시 받아씁니다.
3. **더 정확하게**: 설정 › 음성 인식 › Whisper 모델 크기를 `large-v3`로 (느리지만 가장 정확). 이미 만든 노트는 `⋯ › 다시 변환하기`.
4. **키워드 등록**: 사람 이름·제품명·전문 용어를 적어 두면 그 단어를 훨씬 잘 알아듣습니다.
5. **녹음 환경**: 노트북을 말하는 사람들 가운데 두고, 가능하면 외장 마이크(회의용 스피커폰·핀 마이크)를 쓰세요.
   설정 › 녹음의 `잡음 억제`·`자동 음량 조절`은 화상통화용 처리라 기본으로 꺼 두었습니다.

## 데이터 위치

모든 녹음·대화록·설정은 `~/Library/Application Support/MeetNote`에 있습니다
(설정 › 일반 › Finder에서 열기). 폴더째 백업하면 됩니다.

## 구조

```
meetnote/            Python 엔진 (FastAPI, 127.0.0.1에서만 접속 가능)
  server.py          HTTP API · 녹음 WebSocket · 화면 파일 제공
  pipeline.py        변환 작업 큐: 디코딩 → 음성 인식 → 화자 분리 → 정리 → AI 요약
  engines/           음성 인식 (Whisper MLX / faster-whisper / SenseVoice, 실시간 자막)
  diarize.py         화자 분리 (pyannote 3.0 구간 + CAM++ 목소리 특징) 와 대화록 병합
  korean.py          한국어 띄어쓰기·문장부호 교정, 명사 추출 (Kiwi)
  summarize.py       AI 요약·질문 (Claude / Ollama / 내장 요약)
  export.py          Word · Markdown · 텍스트 · SRT · VTT · JSON
  db.py              SQLite 저장소
web/                 화면 (의존성 없는 HTML/CSS/JS)
scripts/
  install.sh         설치 스크립트
  build_app.sh       회의노트.app 만들기
  MeetNoteApp.swift  네이티브 Mac 창 (WKWebView, 마이크 권한, 다운로드, 인쇄, 메뉴)
tests/               자동 테스트 (실제 한국어 2인 대화로 전체 파이프라인 검증)
```

개발용 실행: `.venv/bin/python -m meetnote` (브라우저로 열림) · 테스트: `.venv/bin/python -m pytest tests`
